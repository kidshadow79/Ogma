# 📋 Dossier Passation

Ce dossier contient les documents de passation entre sessions de développement avec les agents IA.

## Objectif

Lors de sessions de développement longues ou complexes, ces documents permettent de :
- Résumer ce qui a été accompli
- Identifier ce qui reste à faire
- Documenter les décisions architecturales prises
- Faciliter la reprise du travail dans une nouvelle session

## Comment utiliser ces documents

Au début d'une nouvelle session, mentionnez à l'agent :
> "Lis le document de passation dans docs/passation/ pour reprendre le travail sur [sujet]"

L'agent pourra ainsi :
1. Comprendre le contexte du travail précédent
2. Identifier les tâches restantes
3. Continuer le travail là où il s'était arrêté
