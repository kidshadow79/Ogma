# Conversation Storage and Index

**Verified sources**: `conversations/conversation_index.py`, `data/conversations/` (observed structure)

> French version: [../../fr/conversation/01_storage_and_index.md](../../fr/conversation/01_storage_and_index.md)

---

## Storage format

Each conversation is stored in a JSON file in `data/conversations/`. The filename follows the format `YYYY-MM-DD_HH-MM-SS_xxxx.json` where the last 4 characters are a unique short identifier.

A conversation file contains:
- `messages`: chronological list of exchanges `{role, content, timestamp}`
- `summaries`: progressive summaries generated by `ConversationSummarizer`
- Metadata: title, creation date, last modified date

---

## Central index

`data/conversations/index.json` is a dictionary mapping each `conv_id` to its lightweight metadata: title, creation date, last modified date. This index avoids reading all JSON files just to list conversations in the sidebar.

The `load_conversation_index()` and `save_conversation_index()` functions in `conversations/conversation_index.py` manage this index. On read error, the function returns an empty dictionary rather than raising an exception.

---

## Available operations

| Operation | Behavior |
|---|---|
| Create | New JSON file + entry in the index |
| Load | JSON file read by `conv_id` |
| Rename | Title update in both the file and the index |
| Delete | File deletion + removal from index |
| List | Index read only |

---

## `data/conversations/` folder

The folder is created automatically on first launch if absent. Conversations are sorted by date via the chronological file naming format. The `index.json` file is the only non-conversation file in this folder.
