# Extension Data

> French version: [../../fr/data/04_extension_data.md](../../fr/data/04_extension_data.md)

## `data/extensions/`

Folder dedicated to extension-specific data. Currently:

| File | Extension | Role |
|---|---|---|
| `biography_config.json` | Biography Profile | Biography module configuration |

Each extension can create its own subfolder here if it needs voluminous persistent data.

---

## Root `data/` JSON files

JSON files at the `data/` root are either extension **configurations** or generated **outputs**:

**Configurations** (editable, priority over Python):
- `introspection_settings_v2.json` — Cognitive Mirror
- `organic_planner_settings.json` — Organic Planner
- `capability_advisor_config.json` + `capability_advisor_prompt.txt` — Capability Advisor

**Generated outputs** (do not modify manually):
- `ego_compiled.json` — ego traits compiled by EgoCompiler
- `journal_reves.json` + `journal_reves.md` — Dream Engine dream journal
- `archiviste_tokens_debug.jsonl` — Archivist token log (JSONL append-only)

**Reference data** (templates/defaults):
- `identities.default.json` — default identity profile (bootstrap)
- `instructions_defaults.json` + `instructions_defaults_en.json` — default system prompts
- `persistent_context.default.txt` + `persistent_context.default_en.txt` — default persistent context

---

## `data/cognitive_cache/`

Per-conversation cognitive cache. JSON files named by `conv_id`. Maximum 10 conversations kept.

---

## `data/generated_images/`

Images generated by the Text2Image extension. Saved with a timestamped name.

---

## `data/projects/`

Per-project isolated data for the Project RAG extension. Each project has its own subfolder with its SQLite database and FAISS index.
