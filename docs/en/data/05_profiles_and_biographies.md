# Saved Profiles, Biographies, and Identities

**Verified sources**: `profils_sauvegardes/` (direct inspection), `data/biographies/` (direct inspection), `data/identities.json` (inspected in previous sessions)

> French version: [../../fr/data/05_profiles_and_biographies.md](../../fr/data/05_profiles_and_biographies.md)

---

## `profils_sauvegardes/`

Folder for complete profile backups created by `profile_manager.py`. Each backup is a ZIP archive containing the entirety of a user profile's data (memory, conversations, identity, ego).

Structure: `profils_sauvegardes/configs/` — subfolder for configuration backups.

Rotation is limited to 10 backups. The oldest is automatically deleted when the 11th is created.

---

## `data/biographies/`

Structured user portraits generated by the `biographie_profil` extension. The folder contains one subfolder per user identity:

```
data/biographies/
├── user/          ← generic profile
└── yohan/         ← Yohan Brocard profile
```

Each subfolder contains:
- Volume 1: factual synthesis of FAISS memories marked as important
- Volume 2: narrative journal in 10 sections

---

## `data/identities.json`

List of active user identities with their parameters (name, preferred language, associated AI profile). `data/identities.default.json` is the bootstrap template used at first installation.

---

## `data/i18n/`

Interface translation dictionaries:
- `ui_fr.json` — French interface
- `ui_en.json` — English interface

Loaded by `utils/i18n.py` on demand, cached per language.
