# Persistent Data Structure

**Verified sources**: `data/` (direct inspection), `data/settings.example.json` (structure)

> French version: [../../fr/data/01_data_structure.md](../../fr/data/01_data_structure.md)

---

## Overview

The `data/` folder is the source of truth for all of OGMA's persistent data. Nothing is stored in an external database — everything resides in this folder, simplifying backups and portability.

---

## `settings.json` — Central configuration

Main configuration file. Contains parameters for each AI controller, APIs, TTS, and user preferences.

```json
{
  "chat_api": {"provider": "...", "api_key": "...", "backend_type": "API"},
  "reasoning_api": {"provider": "...", "api_model": "..."},
  "embedding_api": {"provider": "...", "backend_type": "API"},
  "tts": {"engine": "...", "voice": "..."},
  "ui_lang": "fr"
}
```

`settings.example.json` provides a configuration template without API keys.

---

## `memory/` — Vector memory

Contains the SQLite database (`memory.db`) and the FAISS index. Automatic backups in `memory/backup/` (10-file rotation).

---

## `conversations/` — Conversation history

Timestamped JSON files (`YYYY-MM-DD_HH-MM-SS_xxxx.json`) and a lightweight `index.json`. Format v2.2+ includes summaries integrated directly in conversation files.

---

## `biographies/` — User portraits

Structured portraits generated by the `biographie_profil` extension. One file per user identity.

---

## `cognitive_cache/` — Per-conversation cognitive cache

JSON files per conversation (`{conv_id}.json`). Maximum 10 kept.

---

## `extensions/` — Extension data

Each extension can have its own data under `data/extensions/{extension_name}/`. This data follows the extension's lifecycle.

---

## Extension configuration files (at `data/` root)

These JSON files take priority over Python default values at runtime:

| File | Extension |
|---|---|
| `introspection_settings_v2.json` | Cognitive Mirror |
| `organic_planner_settings.json` | Organic Planner |
| `capability_advisor_config.json` | Capability Advisor |
| `ego_compiled.json` | Ego System |

**Important**: a new user who clones OGMA loads these JSON files, not the Python constants. They must remain synchronized with the code.

---

## `i18n/` — Translations

Translation dictionaries by language. Loaded by `utils/i18n.py`.

---

## `identities.json` — User identities

List of active user profiles. `identities.default.json` provides the bootstrap configuration.

---

## `persistent_context.txt` — Permanent context

Free text injected into each system prompt. Allows the user to define a permanent context ("I am a developer, I work on...").

---

## `journal_reves.json` / `journal_reves.md`

Dream Engine dream journal. JSON format queryable by the AI, Markdown format for human reading.
