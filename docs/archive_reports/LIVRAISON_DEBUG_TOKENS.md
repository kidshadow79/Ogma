## 🚀 UTILISATION

### Étape 1️⃣ : Lancer OGMA
```bash
python launch_ogma.py
```

✅ Logging **automatiquement activé** (si `archiviste_logger.py` détecté)

### Étape 2️⃣ : Utiliser normalement
- 🕐 Durée recommandée : **1-2 heures**
- 💬 Actions : 10-20 messages variés avec Luna
- 👁️ Logs temps réel dans console :

```bash
python generate_archiviste_report.py
```

- Console : Résumé formaté
