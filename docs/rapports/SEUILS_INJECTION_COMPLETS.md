  - "Saturation cognitive détectée (niveau 5/6). Génère un conseil pour une pause ou un changement de sujet."

- **Niveau 6** : 🔴 **ALERTE CRITIQUE + Pause urgente**
  - ⚠️ **ALERTE CRITIQUE** : "Avertis immédiatement l'utilisateur et recommande fortement une pause"
  - "Saturation critique détectée (niveau 6/6). Génère un conseil pour une pause cognitive constructive."

## 🔑 LÉGENDE SYSTÈME D'ALERTES

### 🚨 Types d'alertes
- **⚠️ ALERTE UTILISATEUR** : Information directe à l'utilisateur (saturation niveau 4+)
- **ℹ️ INFO UTILISATEUR** : Information positive à l'utilisateur (stimulation niveau 5+)
- **💡 CONSEIL ARCHIVISTE** : Injection comportementale interne
- **🚫 AUCUNE ACTION** : États naturels, observation passive

### 🎨 Codes couleur LED
- 🟢 **Vert** : État optimal
- 🟡 **Jaune** : État modéré  
- 🟠 **Orange** : État notable
- 🔴 **Rouge** : État critique
- 🔵 **Bleu** : Créativité (stimulation)
- 🟣 **Violet** : Innovation créative
- 🌸 **Rose** : Transcendance/Passion
