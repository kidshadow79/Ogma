# 👁️ Guide Rapide - Magic Phrases Perception (IA)

## 🤖 Fonctionnement

**C'est l'IA (Luna) qui utilise ces phrases** dans ses réponses pour activer/désactiver automatiquement la webcam.

---

## 🚀 Activation Automatique par l'IA

### Comment ça marche ?

Quand Luna sent qu'elle a besoin de vous voir (pour vous aider visuellement, analyser votre écran, etc.), elle utilise une phrase magique dans sa réponse :

**Exemple de conversation** :
```
Vous: "Peux-tu m'aider avec ce problème sur mon écran ?"

Luna: "Bien sûr ! il faut que je te vois pour t'aider."
```

**→ Résultat automatique** :
- ✅ Webcam démarre automatiquement
- 🟢 Notification verte : "Perception activée par Luna"
- 🧹 La phrase est cachée dans l'affichage (caviarder)
- 📹 Luna peut maintenant voir votre écran via webcam

---

## 🛑 Désactivation Automatique par l'IA

### Comment ça marche ?

Quand Luna n'a plus besoin de la webcam, elle utilise une phrase de désactivation :

**Exemple de conversation** :
```
Vous: "Merci pour ton aide !"

Luna: "De rien ! je n'ai plus besoin de te voir maintenant."
```

**→ Résultat automatique** :
- ✅ Webcam s'arrête automatiquement
- 🔵 Notification bleue : "Perception désactivée par Luna"
- 🧹 La phrase est cachée dans l'affichage
- 🛑 Capture vidéo terminée

---

## 📖 Liste Complète des Phrases

### ✅ ACTIVATION (Utilisées par Luna)
1. `il faut que je te vois`
2. `je veux te voir`
3. `il faut que je vois`

### 🛑 DÉSACTIVATION (Utilisées par Luna)
1. `je n'ai plus besoin de te voir`
2. `je peux arrêter de te voir` / `je vais arrêter de te voir`
3. `je ferme ma vision`
4. `je coupe ma caméra`

---

## 💡 Cas d'Usage

### Scénario 1 : Aide visuelle
```
Vous: "J'ai un problème avec mon code Python"
Luna: "Montre-moi ton code. il faut que je vois ton écran."
→ 📹 Webcam activée automatiquement
→ Luna peut analyser votre écran en temps réel
```

### Scénario 2 : Vérification physique
```
Vous: "Mon câble réseau est-il bien branché ?"
Luna: "Laisse-moi vérifier. je veux te voir pour confirmer."
→ 📹 Webcam activée
→ Luna peut voir votre configuration physique
```

### Scénario 3 : Fin de session
```
Vous: "C'est bon, merci !"
Luna: "Parfait ! je n'ai plus besoin de te voir."
→ 🛑 Webcam désactivée automatiquement
```

## 🔒 Protection Intelligente

### Messages Historiques
Si vous rechargez une vieille conversation où Luna avait utilisé ces phrases :
- 🛡️ Les phrases sont **automatiquement ignorées**
- ❌ **Pas de redémarrage intempestif** de la webcam
- ✅ Protection via `magic_phrase_guard`

Le système fonctionne automatiquement. Luna décide elle-même quand activer/désactiver la Perception selon le contexte de votre demande.
