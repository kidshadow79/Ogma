Plan d'Action : Migration Mémoire OCTOPUS v2.0 (Phase 1 - CPU Stable)
À : IA Assistante de Codage
De : Yohan (Architecte du Projet)
Objet : Migration du système de mémoire MnéaCloud de JSON vers une architecture SQLite + FAISS-CPU, en intégrant le rôle de l'IA Archiviste au cœur du processus.

1. Contexte & Objectif de la Phase 1
L'actuel système de mémoire basé sur un fichier JSON est obsolète. L'objectif est de le remplacer par une architecture performante, stable et intelligente.

Cette Phase 1 se concentre sur la mise en place du cœur de la nouvelle mémoire : une base de données SQLite pour le stockage structuré, un index FAISS-CPU pour une recherche rapide et fiable, et l'orchestration par une IA Archiviste pour l'enrichissement et la synthèse contextuelle.

Ce qui est inclus dans cette phase :

Remplacement complet du fichier JSON.

Stockage des souvenirs structurés dans SQLite.

Indexation des vecteurs sur le CPU avec FAISS.

Intégration de l'IA Archiviste pour l'analyse à l'écriture et la synthèse à la lecture.

Ce qui est explicitement exclu de cette phase (reporté) :

Les algorithmes de "mémoire vivante" (décroissance, compaction, etc.).

Le planificateur de tâches (APScheduler).

2. Environnement Technique
Système d'exploitation : Windows 11 (environnement local)

Processeur : Ryzen 7 7700x

Langage : Python 3.10+

3. Directives Techniques Séquentielles
Étape 1 : Installation des Dépendances
Ajouter les bibliothèques suivantes au projet via la commande pip. Cette version est choisie pour sa stabilité et sa simplicité d'installation.

pip install faiss-cpu sqlalchemy

Étape 2 : Nouvelle Structure des Données
1. Base de données SQLite (data/memory/memories.db) :
Créer une table memories qui stockera les souvenirs enrichis par l'Archiviste.

CREATE TABLE IF NOT EXISTS memories (
  id TEXT PRIMARY KEY,
  created_at TEXT NOT NULL,
  text_original TEXT NOT NULL,
  title TEXT,          -- Généré par l'Archiviste

2. Index FAISS (data/memory/faiss.index) :
Fichier binaire stockant les vecteurs pour la recherche CPU.
